⚙️ 接口设置

支持任何 OpenAI 兼容接口（DeepSeek / 硅基流动 / 通义 / 本地 Ollama 等）。Key 只存在你这台设备的浏览器里，不上传任何地方。

🎭 人设（军师的性格）

改这里就能换风格。默认设定：直接、不哄人、给具体动作、不说空话。

📋 我的背景（军师每次都会看到）

把你自己的情况写这儿——越具体，他的建议越准。以后有变化随时改。背景**不会**被截断，写多长都会完整发过去。

🙂 表情

关掉之后它就只跟你讲干货，一个表情都不加。你自己照样可以随时用 🙂 按钮发表情。

🎤 朗读与语音

军师每条回复下面有「▶ 朗读」：点一下从头读，按钮变成「⏹ 停止」； 点回复里的任意一个字，就从那个字往下读；读的时候点别处一下就停，高亮和外框都会清掉。
嗓音是手机系统自带的，网页没法凭空造出某个人的声音（林志玲那种是商业授权音源，浏览器里拿不到）。 但每台设备/浏览器自带的中文嗓音不一样，这里换一个 + 把音调调高、语速调慢，就能明显更顺耳更人性化。
觉得选择太少就去装语音包：安卓「设置 → 系统 → 语言和输入 → 文字转语音 → 安装语音数据」；iPhone「设置 → 辅助功能 → 朗读内容 → 声音 → 中文」。
语音输入用输入框旁边的 🎤（安卓 Chrome / 电脑上能用）。iPhone 上系统不给网页语音识别， 点 🎤 会自动帮你调出键盘，用键盘自带的 🎤 听写。
