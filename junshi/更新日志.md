# 更新日志

## v2.5 — 2026-10-04

**要 Siri 的音色 —— 做到了。要林志玲的音色 —— 做不到，下面说清为什么。**

### ✅ Siri 音色：加了「📢 Siri 读」按钮
每条军师回复下面多了一个 **📢 Siri 读**。点它 → 内容交给系统 → **两根手指从屏幕顶部往下滑**，
Siri 就用来说话了；再点一下屏幕停。

这条路能成，是因为 **iOS 的「朗读屏幕」用的就是 Siri 的声音**，而它能读任何页面。
第一次要开：设置 → 辅助功能 → 朗读内容 → 打开「朗读屏幕」；换声音在同页 → 声音 → 中文。

实现上：优先走**系统分享**（`navigator.share`，iPhone 上会弹分享面板），
不支持分享就退回复制，再不行也会把操作步骤告诉你——**自动复制失败不挡说明**。

### ❌ 林志玲音色：没有路，我说实话
那是**商业授权音源**（跟高德导航里的明星语音包一样），只有 App 厂商付费内置才有。
网页只能用设备系统自带的语音合成，没有任何接口能拿到明星音色。

### ⚠️ 为什么网页直接读不出 Siri
Siri 的声音锁在 **iOS 私有框架**里。网页的 `speechSynthesis.getVoices()` 拿到的是系统那几十个基础音，
**Siri 不在里面** —— 这不是我偷懒，是浏览器层面就没有这个能力。所以只能绕：把文字交给系统的朗读屏幕。

### 顺带改的
- 「▶ 朗读」按钮的悬浮提示里写清了「也可点正文某个字，从那里读」
- 设置页把两条路的边界写明白了：Siri 走系统朗读屏幕，林志玲没有路

## v2.4 — 2026-10-04

**修了朗读的三个毛病 + 加了嗓音选择。**

### 1. 按钮图标：三角 ↔ 方块
以前是「🔊 朗读 / ⏹ 停止」，喇叭和方块不统一。现在空闲是 **▶ 朗读**、朗读中是 **⏹ 停止**，
标准播放/停止图标，一眼能看出当前状态。

### 2. 点空白处：高亮和外框一起清掉
以前正在读的时候点别处，**只剩切换、不清理**——黄底高亮和那个橙色外框会一直留在原地。
现在所有停止路径都统一走同一个复位函数：

- 点按钮停
- **点正文里别的地方**（切到另一段、或再点一下当前段）
- 点另一条消息的朗读
- 切对话、发新消息、切到后台
- 读完了自动复位

以上每一种都会把**高亮、外框、按钮图标**三样一起清干净。

### 3. 嗓音：能换了（但说清楚一件事）
设置里新增「🎤 朗读与语音」：

- **朗读嗓音**下拉框：列出你设备里**所有中文嗓音**（会自动排除英文的），标注「离线」「偏女声」
- **语速**滑块 0.6–1.8 倍
- **音调**滑块 0.6–1.9（调高更年轻、更接近"御姐"）
- **▶ 试听这个嗓音**按钮：用当前设置读一句话，边调边听，满意为止
- 三项都是**一改就生效**，不用点保存；正在读的时候改会立刻用新嗓音接着读

> **关于"换成林志玲的声音"——这个做不到，我说实话。**
> 网页只能用**设备系统自带**的语音合成，浏览器拿不到任何明星音色。
> 林志玲、导航里的郭德纲那些都是**商业授权音源**，只有 App 厂商付费内置才有。
> 能做的、也是我做了的：把系统里所有中文嗓音摆出来让你挑，加上音调和语速微调。
> 实测这台电脑的 Edge 里就有 17 个中文嗓音，其中 `Microsoft 晓晓 Online (Natural)`、
> `Microsoft 晓伊 Online (Natural)` 是神经网络音，明显比默认那个自然得多，值得先试这两个。
>
> 觉得选择太少就装语音包（设置页里写了路径）：安卓「文字转语音 → 安装语音数据」，
> iPhone「辅助功能 → 朗读内容 → 声音 → 中文」。

### 顺带修的
- `u.voice = 嗓音对象` 如果抛异常（语音包被卸载、列表变了），会**整条朗读链中断**。
  现在加了保护，退化成默认嗓音继续读完，不会卡死。

## v2.3 — 2026-10-04

**输入区改成微信那个样子了。**

### 新布局（照微信做的）
```
┌────────────────────────────┬──────┐
│  说点什么…                  │ 发送 │
└────────────────────────────┴──────┘
  🎤   🙂   ➕
```
- 输入框占满左边、**发送**在右边同一行
- 下面一排三个键：**🎤 语音**、**🙂 表情**、**➕ 更多**
- 点 **➕** 弹出面板（就是微信那个宫格）：**相册 / 拍摄 / 文件 / 语音输入 / 清空当前 / 导出对话 / 对话历史 / 设置**
- 点 **🎤** 整行变成长条按钮，**按住说话、松开结束**，上面还会给一行提示
- ➕ 和 🙂 互斥，点一个另一个自动收起；按 Esc 全部收起

### 顺手改掉的
- **iPhone 上的语音入口不再"消失"**：以前不支持语音识别我就把 🎤 藏了，现在 🎤 还在，
  点它 → 自动聚焦输入框并提示你用**键盘自带的 🎤 听写**（设置 → 通用 → 键盘 → 启用听写）。
  这是 iOS 上唯一可行的办法，微信也一样绕不开系统限制。
- 原来散在输入框旁边的 🖼 图片按钮收进 ➕ 面板了，输入区干净了。

### 修掉的布局 bug
- 输入框曾经被压成 193px（因为容器用了 `justify-content:flex-end`，导致没有剩余空间，
  `flex:1` 反而失效）。改成 `flex-start` + `flex:1 1 auto; width:0` 后才真正占满。

## v2.2 — 2026-10-04

**加了朗读、语音输入、QQ 表情。**

### 🔊 朗读（可以从句中任意一个字开始）
- 每条军师回复下面有 **「🔊 朗读」**，点一下从头读，按钮变成「⏹ 停止」。
- **点回复里的任意一个字，就从那里往下读**——想跳过前面直接听结论，点结论那个字就行。
- 按**句子**切块朗读（不是按标点硬切），所以从某个字点进去，会自然地从那句话读起。
- 正在读的那一段会**黄底高亮**，一眼知道读到哪了。
- 一条一条排队读完；读的时候点别处会自动切过去。
- 用手机自带语音，**不联网、不额外花钱**。

### 🎤 语音输入（语音转文字）
- 输入框旁边有 🎤，点一下开始说，识别出来的字**插到光标位置**（不会冲掉你已经打的字）。
- 边说边出字（中间结果半透明显示），说完再点一下结束。
- 安卓 Chrome / 电脑上能用。
- ⚠️ **iPhone 上系统不允许网页用语音识别**，所以 🎤 会自动隐藏。iPhone 用键盘自带的 🎤 听写：
  设置 → 通用 → 键盘 → 启用听写。那个还更准。

### 🙂 QQ 表情
- 输入框旁边的 🙂 打开表情面板，**72 个常用表情**，点一下插到光标处。
- **支持 QQ 代码**：直接打 `/微笑`，发出去就显示成 😊。你和军师都能用。
- 军师也会用表情回你（比如 `/抱拳` `/微笑`），可以在设置里**关掉**——关掉它就只讲干货。
- 开关在「设置 → 🙂 表情」。

> **为什么不用 QQ 官方表情图片？** 那些图是腾讯的版权资源，扒下来自己托管有风险。
> 所以改用系统 emoji：离线可用、任何手机都能显示、微信里也能直接发出去。

### 顺带修的
- 表情渲染避开代码块和网址：`` `/微笑` ``、`http://a.cn/b`、分数 `1/2` 都不会被误伤。
- 渲染逻辑重写：不再对整串做转义，避免表情被转义坏掉。
- 「点某个字开始读」的定位做了对齐：原来的实现会差一个字（点第 20 个字、却从第 19 个字读起）。

## v2.1 — 2026-10-04

**加了读图功能**：可以把图片直接发给军师看。

### 怎么发图
- 点输入框右边的 **🖼** 按钮，从相册/文件里选（可多选）
- 或者**直接粘贴**（复制截图后粘贴，手机上最顺手）
- 也可以把图片文件**拖进页面**

选好的图会出现在输入框上方的小条里，每张右上角有个 ✕ 可以去掉，旁边显示一共几张、多大。
点缩略图能放大看。一条消息最多 4 张。

### 图片会自动处理
- 发送前自动**缩放 + 转 JPEG**：最长边压到 896px，目标 300KB 以内（超了就逐级降质量）。
  实测一张 1.3MB / 2600×1900 的手机照片，压完约 250KB。
- PNG 的透明底会先铺白底再转 JPEG，不然透明区会变成黑的。
- 你可以直接发手机原图（最大允许 12MB），不用自己先处理。

### 有两个坑替你填了
1. **模型不认图时自动降级**：如果模型返回"不支持 image_url"这类错误，会自动去掉图片、用纯文字再问一次，
   并提示你换成支持视觉的模型。不会让你那条消息白写。
2. **发失败时图片和文字一起还给你**：以前只有文字会退回输入框，现在图也回到待发条里，不用重新选。

### ⚠️ 要看图，模型必须支持视觉
**DeepSeek 官方的 `deepseek-chat` 只认文字，发图会被拒。**
能看图的常见选择：`qwen-vl-max`（通义 / 硅基流动）、`glm-4v`（智谱）、`gpt-4o`（OpenAI）。
换成这类模型后，「设置」里的模型名一改就能用。

### 其他
- 快捷按钮多了一个「看图」
- 设置里新增**本机存储占用**显示（图片占地方，上限约 5MB，满了会提示你删旧对话）
- 消息里的图**放在气泡外面**，所以「复制」拿到的是纯文字，不会带一坨乱码

## v2.0 — 2026-10-04

这一版主要是**修好手机上打字框会被放大**的问题，外加把「只有一个对话、不能回退」的短板补上。

### 修掉的 bug

1. **打字框一点就放大页面（iOS）**
   原因是输入框字号小于 16px，iOS Safari 聚焦时会强制放大网页，而且失焦后不会自己缩回去，必须双指捏。
   - 底部打字框 `15px → 16px`
   - 设置里的接口框 / 人设框 / 背景框 `14px → 16px`
   - `<meta viewport>` 补上 `maximum-scale=1.0` 兜底

2. **打字框被占位文字撑成两行、底部被裁**
   占位文字太长（"说点什么…（Enter 发送，Shift+Enter 换行）"）在小屏换行，把输入框撑成两行。
   改成短占位文字 + `min-height:44px` + `max-height:130px`。

3. **历史抽屉搜索框同样被裁** —— 占位文字改短。

4. **旧对话没有标题**
   从旧版本升上来的对话、或刷新页面后打开的对话，标题栏一直显示"军师"。现在渲染前统一补标题。

5. **发送失败会污染上下文**
   以前 API 失败时，你那句话已经进了历史列表，界面上却看不到它"发成功过"，下一轮对话模型还会看到这条孤零零的消息。现在失败会**把这句话从历史里撤掉、放回输入框**。

6. **用户气泡里的代码块黑白撞色** —— 蓝底上用半透明深色。

### 新增功能

| 功能 | 说明 |
|---|---|
| **多对话 + 历史记录** | 左上角 ☰ 打开。每个话题一个独立对话，自动用第一句话当标题；支持搜索内容、切换、逐个删除。**旧版本的对话会自动迁移过来，不会丢。** |
| **停止生成** | 生成过程中「发送」变成红色「停止」，点一下立刻中断。已经收到的部分会保留，标注"（手动中止）"。 |
| **消息级操作** | 每条消息下面有按钮：复制 / 删除；我问的还能「重发」，军师答的能「重新回答」或「引用追问」。 |
| **引用追问** | 点一下自动把"关于你上面说的「…」，我再问一句："填进输入框，方便追问细节。 |
| **测试连接** | 设置面板里一键验证接口地址、Key、模型名对不对，并把真实报错拿出来（余额不足 / 模型名错 / Key 失效一眼看清）。 |
| **撤销与重来** | 删错消息直接删；答得不满意就「重新回答」，不会像以前那样只能清空重开。 |
| **导出** | 「导出当前」导一个对话，「导出全部」把所有对话一次性备份成 txt。 |
| **背景资料不限长度** | 以前人设和背景资料会被 24 条消息的截断规则波及；现在**背景资料永远完整发送**，只截断聊天记录本身（最近 24 条，省 token）。 |
| **未保存提醒** | 设置里改了没保存，按钮会变成「保存 •」，直接关面板或切走会问一句，不再默默丢改动。 |

### 内部改动

- 存储结构从"单一消息数组"升级为"对话列表"：`junshi_conv_v1` + `junshi_act_v1`。
  **旧键 `junshi_msg_v1` 保留不动**，当备份用。
- 加 `Content-Security-Policy` meta 收紧脚本与资源来源。
- 接口返回 `application/json`（有些兼容接口不吃 `stream`）时自动退化成一次性返回。
