# 更新日志

## v2.6 — 2026-10-04

**修了嗓音列表重复的 bug，并把 iPhone 上真实的情况摊开说清。**

### 修掉的 bug

1. **嗓音下拉框里全是重复项**
   iPhone 会把同一个嗓音按不同语言变体报好几遍（名字都一样）。
   实测一台 iPhone 列出的是「婷婷 / 婷婷 / 美嘉 / 美嘉」——四个选项里只有两个是真的。
   现在按名字去重，只剩两个真的。

2. **“一个中文嗓音都没有”的提示永远不显示**
   条件写错了：把“一个嗓音都拿不到”和“有嗓音但没中文”混成了一种情况。

### 诊断面板现在会说人话

四种情况分开说：

| 情况 | 面板会说什么 |
|---|---|
| 一个嗓音都拿不到（iOS 首次进设置） | 要先用一次朗读，再点「重新扫描嗓音」 |
| 有嗓音但没中文的 | 给出装声音的完整路径 |
| **只有 iOS 老式离线嗓音** | **直说这些都很机械，并告诉你网页拿不到晓晓那种自然音** |
| 有 (Natural) 嗓音 | 推荐优先试那几个 |

### ⚠ 必须说清楚的一件事

**iPhone 上网页拿不到晓晓 / 晓伊那种自然音。**
实测一台 iPhone：一共报 71 个嗓音，去重后中文只有 **婷婷** 和 **美嘉**，
而且都是 iOS 自带的老式离线嗓音。系统里那些 Natural 声音只给“朗读屏幕”用，
网页的语音接口看不到它们。所以 iPhone 上只有两条路：

1. **用「Siri 读」按钮**（推荐）—— 走系统的朗读屏幕，那是 Siri 的声音，比婷婷、美嘉好听得多
2. 在婷婷 / 美嘉里挑一个，配合把音调往上拖、语速调慢

## v2.5 — 2026-10-04

**要 Siri 的音色 —— 做到了。要林志玲的音色 —— 做不到。**

### Siri 音色：加了「Siri 读」按钮
每条回复下面多一个按钮，点它 → 内容交给系统 → **两根手指从屏幕顶部往下滑**，
Siri 就开始读；再点一下屏幕停。
第一次要开：设置 → 辅助功能 → 朗读内容 → 打开「朗读屏幕」。
实现上优先走系统分享，不支持就退回复制，**复制失败也不挡操作教程**。

### 林志玲音色：没有路
那是**商业授权音源**（跟高德导航里的明星语音包一样），只有 App 厂商付费内置才有。
网页只能用设备系统自带的语音合成。

### 为什么网页直接读不出 Siri
Siri 的声音锁在 **iOS 私有框架**里，网页的 speechSynthesis 拿不到。
所以只能绕：把文字交给系统的朗读屏幕。

## v2.4 — 2026-10-04

**修了朗读的三个毛病 + 加了嗓音选择。**

1. **按钮图标：三角 ↔ 方块**：空闲是「▶ 朗读」、朗读中是「⏹ 停止」。
2. **点空白处：高亮和外框一起清掉**。所有停止路径（按钮、点别处、切对话、发消息、切到后台、读完）
   都走同一个复位函数，三样一起清。
3. **嗓音可选**：设置里新增嗓音下拉 + 语速滑块（0.6–1.8）+ 音调滑块（0.6–1.9，调高更接近“御姐”）+ 试听按钮。
   一改就生效，不用点保存。

顺带修了：`u.voice = 嗓音对象` 抛异常时会**中断整条朗读链**，现在退化成默认嗓音继续读完。

## v2.2 — 2026-10-04

**加了朗读、语音输入、QQ 表情。**

### 朗读（可以从句中任意一个字开始）
点一下从头读；**点回复里的任意一个字，就从那里往下读**；
按**句子**切块，正在读的那段黄底高亮。用手机自带语音，不联网、不花钱。

### 语音输入（语音转文字）
识别出的字插到光标位置，不会冲掉已经打的字。安卓 Chrome / 电脑上能用。
⚠ **iPhone 上系统不允许网页用语音识别**，走键盘自带听写。

### QQ 表情
72 个常用表情，点一下插到光标处；**也支持 / 代码**（打 `/ 微笑` 就出表情）。
军师也会用表情回你，可在设置里关掉。
> 为什么不用 QQ 官方表情图片？那些是腾讯的版权资源，自托管有风险。
> 所以用系统 emoji：离线可用、任何手机都显示、微信里也发得出去。

## v2.1 — 2026-10-04

**加了读图功能。**

点「相册」选图、**截图后直接粘贴**、或拖进页面。一条最多 4 张。
发送前自动压缩：最长边 896px、目标 300KB（实测 1.3MB 的手机照片压到 250KB）。
PNG 透明底会先铺白底再转 JPEG，不然会变黑。

> ⚠ **要看图，模型必须支持视觉。** DeepSeek 官方的 deepseek-chat 只认文字。
> 能看图的：qwen-vl-max、glm-4v、gpt-4o 这类。
> 模型不认图时，会自动去掉图、只用文字再问一次。

## v2.0 — 2026-10-04

**修好了手机上打字框会被放大的问题，并把“只有一个对话”的短板补上。**

### 修掉的 bug
1. **打字框一点就放大页面（iOS）**：输入框字号小于 16px，
   iOS 聚焦时会强制放大网页，失焦后不会自己缩回。现在都顶到 16px。
2. **打字框被占位文字撑成两行**：占位文字改短 + min-height/max-height。
3. **历史搜索框被裁**。
4. **旧对话没标题**：渲染前统一补标题。
5. **发送失败会污染上下文**：现在把这句话从历史里撤掉、放回输入框。
6. **用户气泡里的代码块黑白撞色**。

### 新增功能
- **多对话 + 历史**：每个话题一个独立对话，自动用第一句话当标题，能搜内容、能删。
  **旧版本的对话会自动迁移过来。**
- **停止生成**：生成中「发送」变红色「停止」，已收到的部分保留。
- **消息级操作**：复制 / 删除；我的能重发，它答的能重新回答、引用追问。
- **测试连接**：一键验证接口地址 / Key / 模型名。
- **导出当前 / 导出全部**。
- **背景资料不限长度**：人设 + 背景永远完整发送，只截聊天记录（最近 24 条）。
- **未保存提醒**。
