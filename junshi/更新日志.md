# 更新日志

## v2.0 — 2026-10-04

这一版主要是**修好手机上打字框会被放大**的问题，外加把「只有一个对话、不能回退」的短板补上。

### 修掉的 bug

1. **打字框一点就放大页面（iOS）**
   原因是输入框字号小于 16px，iOS Safari 聚焦时会强制放大网页，而且失焦后不会自己缩回去，必须双指捏。
   - 底部打字框 `15px → 16px`
   - 设置里的接口框 / 人设框 / 背景框 `14px → 16px`
   - `<meta viewport>` 补上 `maximum-scale=1.0` 兜底

2. **打字框被占位文字撑成两行、底部被裁**
   占位文字太长（"说点什么…（Enter 发送，Shift+Enter 换行）"）在小屏换行，把输入框撑成两行。
   改成短占位文字 + `min-height:44px` + `max-height:130px`。

3. **历史抽屉搜索框同样被裁** —— 占位文字改短。

4. **旧对话没有标题**
   从旧版本升上来的对话、或刷新页面后打开的对话，标题栏一直显示"军师"。现在渲染前统一补标题。

5. **发送失败会污染上下文**
   以前 API 失败时，你那句话已经进了历史列表，界面上却看不到它"发成功过"，下一轮对话模型还会看到这条孤零零的消息。现在失败会**把这句话从历史里撤掉、放回输入框**。

6. **用户气泡里的代码块黑白撞色** —— 蓝底上用半透明深色。

### 新增功能

| 功能 | 说明 |
|---|---|
| **多对话 + 历史记录** | 左上角 ☰ 打开。每个话题一个独立对话，自动用第一句话当标题；支持搜索内容、切换、逐个删除。**旧版本的对话会自动迁移过来，不会丢。** |
| **停止生成** | 生成过程中「发送」变成红色「停止」，点一下立刻中断。已经收到的部分会保留，标注"（手动中止）"。 |
| **消息级操作** | 每条消息下面有按钮：复制 / 删除；我问的还能「重发」，军师答的能「重新回答」或「引用追问」。 |
| **引用追问** | 点一下自动把"关于你上面说的「…」，我再问一句："填进输入框，方便追问细节。 |
| **测试连接** | 设置面板里一键验证接口地址、Key、模型名对不对，并把真实报错拿出来（余额不足 / 模型名错 / Key 失效一眼看清）。 |
| **撤销与重来** | 删错消息直接删；答得不满意就「重新回答」，不会像以前那样只能清空重开。 |
| **导出** | 「导出当前」导一个对话，「导出全部」把所有对话一次性备份成 txt。 |
| **背景资料不限长度** | 以前人设和背景资料会被 24 条消息的截断规则波及；现在**背景资料永远完整发送**，只截断聊天记录本身（最近 24 条，省 token）。 |
| **未保存提醒** | 设置里改了没保存，按钮会变成「保存 •」，直接关面板或切走会问一句，不再默默丢改动。 |

### 内部改动

- 存储结构从"单一消息数组"升级为"对话列表"：`junshi_conv_v1` + `junshi_act_v1`。
  **旧键 `junshi_msg_v1` 保留不动**，当备份用。
- 加 `Content-Security-Policy` meta 收紧脚本与资源来源。
- 接口返回 `application/json`（有些兼容接口不吃 `stream`）时自动退化成一次性返回。
