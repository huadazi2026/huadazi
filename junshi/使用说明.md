# 军师 · 使用说明

一个只给你自己用的私人顾问 App。网页版、单文件、能加到手机主屏幕像原生 App 一样打开。

线上地址：https://huadazi2026.github.io/huadazi/junshi/

---

## 第一次用

1. 打开上面的地址（手机上用 Safari / Chrome 打开）。
2. **加到主屏幕**：Safari 点分享 → 「添加到主屏幕」；Chrome 点右上角 ⋮ → 「添加到主屏幕」。
   之后就有一个「军师」图标，点开是全屏的，没有浏览器地址栏。
3. 点右上角 **设置**，填三样东西：
   - **接口地址**：默认 `https://api.deepseek.com/v1`（任何 OpenAI 兼容接口都行）
   - **API Key**：你的 `sk-...`
   - **模型名**：默认 `deepseek-chat`
4. 填完点 **🔌 测试连接** 确认通了，再点 **保存**。

> Key 只存在你这台手机的浏览器里（localStorage），不上传任何服务器。但**别在别人手机上填**。

## 日常怎么用

### 直接聊
底部输入框打字，Enter 发送，Shift+Enter 换行。手机上按键盘的换行就是换行。

下面那排快捷按钮是常用的开场白，点一下就发：
「理一遍处境」「我该怎么做」「我是不是在骗自己」「帮我回话」「钱怎么规划」。

### 让它了解你（最关键的一步）
设置里的 **📋 我的背景**，把你自己的情况写进去——年龄、钱的大致状况、工作、关系、你在纠结什么。
**军师每次回答都会看到这段**，写得越具体，它给的判断越准。情况变了就回来改。

这段**不会被截断**，写多长都会完整发过去。

### 换性格
设置里的 **🎭 人设** 决定它怎么跟你说话。默认是"直接、不哄人、给具体动作、不说空话"。
嫌太冲就自己改，比如加一句"语气缓和点，但别哄我"。

### 让它看图
军师能看图片——截图、转账记录、聊天截图、体检单、任何你懒得打字描述的东西。

三种发法，挑顺手的：
- 点输入框右边的 **🖼** 按钮选图（可以一次选多张）
- **截图之后直接粘贴**（手机上最快）
- 电脑上把图片文件拖进页面

选好的图会显示在输入框上方的小条里，点 ✕ 能去掉，点缩略图能放大看。一条最多 4 张。

图片会自动压缩（1MB 多的手机照片压到 250KB 左右），**直接发原图就行，不用自己处理**。

> ⚠️ **要看图，模型得支持视觉。** DeepSeek 官方的 `deepseek-chat` 只认文字，发图会被拒。
> 能看图的常见选择：`qwen-vl-max`（通义/硅基流动）、`glm-4v`（智谱）、`gpt-4o`（OpenAI）。
> 在「设置」里把模型名换掉就能用。
> 万一用了不支持的模型，军师会自动去掉图片、只用文字再问一次，不会让你白写。

### 输入区（跟微信一样）
```
┌────────────────────────────┬──────┐
│  说点什么…                  │ 发送 │
└────────────────────────────┴──────┘
  🎤   🙂   ➕
```
输入框占左边，**发送**在右边，下面一排三个键。

点 **➕** 弹出面板：

| | |
|---|---|
| 🖼 相册 | 从相册/文件选图，可多选 |
| 📷 拍摄 | 直接调相机拍一张 |
| 📁 文件 | 从文件里选 |
| 🎤 语音输入 | 切到语音模式（同下面的 🎤） |
| 🧹 清空当前 | 清空这个对话的消息 |
| 💾 导出对话 | 备份成 txt |
| 🗂 对话历史 | 打开历史列表 |
| ⚙️ 设置 | 打开设置 |

> 截图之后**直接粘贴**也能发图，不用点 ➕，这个最快。

### 用嘴说，不用手打
点 **🎤**，输入框那一行会变成长条按钮：**按住说话、松开结束**。识别出来的字接在你正在打的字后面。

- **安卓 Chrome / 电脑**：直接用，边说边出字。
- **iPhone**：系统不给网页麦克风权限（微信也绕不开）。所以点 🎤 它会**自动帮你弹出键盘**，
  你点键盘右下角那个 🎤 听写就行——效果其实更好。
  第一次要先开：设置 → 通用 → 键盘 → 启用听写。

### 让它读给你听
每条军师回复下面都有 **🔊 朗读**：

- 点一下**从头读**，按钮变成「⏹ 停止」，再点一下停。
- **想跳过前面直接听结论？点结论里的任意一个字，就从那里往下读。** 正在读的那段会黄底高亮。
- 用手机自带语音，不联网、不花钱。

### 发表情
点 **🙂**，打开是 72 个常用表情，点一下插到光标处。

也可以**直接打 QQ 代码**：打 `/微笑` 就会显示成 😊。常用的一批：

```
/微笑  /呲牙  /偷笑  /坏笑  /大笑  /流泪  /大哭  /难过
/强    /弱    /抱拳  /鼓掌  /握手  /胜利  /奋斗  /玫瑰
/爱心  /心碎  /蛋糕  /啤酒  /猪头  /便便  /炸弹  /太阳
```

军师也会用表情回你。**不想要就关掉**：设置 → 🙂 表情 → 取消勾选，它就只跟你讲干货。

### 多个话题分开聊
左上角 **☰** 打开对话历史。每个话题一个独立对话，不会互相串。
- 点标题切换过去
- 上面搜框能搜对话内容
- 右边 ✕ 删掉（删了找不回来）

开着新话题就点右上角 **新对话**。

### 回答不满意
每条消息下面有小按钮：

| 按钮 | 作用 |
|---|---|
| 复制 | 把这整条复制走 |
| 重发 / 重新回答 | 从这条重新问一遍（后面的内容会撤掉重来） |
| 引用追问 | 把"关于你上面说的「…」，我再问一句："填进输入框 |
| 删除 | 单条删掉，删错了就当没问过 |

生成到一半觉得不对，点红的 **停止** 就能中断，已经出来的部分会留着。

### 备份
设置里 **导出当前** 导一个对话，**导出全部** 把所有对话一起导成 txt。
换手机、清缓存之前记得导一次——**对话只存在这台设备上，没有云端同步**。

## 遇到问题

**点输入框页面放大了**
v2.0 已修。如果还有，说明手机加载的是旧页面——强制刷新一次（下拉刷新，或清一次 Safari 缓存）。

**提示"没发出去，话给你放回输入框了"**
接口没通。按顺序查：设置里的接口地址有没有写错 → Key 有没有过期 → 手机网络能不能通。
用 **🔌 测试连接** 最快，它会告诉你真实原因（余额不足 / 模型名错 / Key 失效）。

**回复很慢或卡住**
点 **停止** 重来。生成中途可以直接点停止，不用等。

**换手机后对话没了**
对话存在本机浏览器里，换设备不会同步。用「导出全部」备份，或者在新手机上重新开始。

**发图它说看不到 / 报错说 image_url 不支持**
当前模型不支持视觉。去「设置」换成 `qwen-vl-max`、`glm-4v`、`gpt-4o` 这类。军师会自动降级成纯文字再问一次，但那样它确实看不到图。

**存不下了**
图片比较占地方，浏览器上限约 5MB。去「设置」看当前占用，满了就在 ☰ 里删几个带图的旧对话。

**标题栏显示"军师"而不是话题名**
说明这个对话还没有你发过的消息，发一句就会自动命名。

**点了朗读没声音**
先确认手机没静音、媒体音量开了。如果还是没声音，说明你这台设备的浏览器没装中文语音——安卓可以在「设置 → 文字转语音」里装一个中文引擎。

**🎤 按钮不见了**
iPhone 上必然不见（系统限制）。安卓上如果也没有，说明你的浏览器不支持语音识别，换个 Chrome 试试。

## 技术备忘（给自己看）

- 纯前端单文件 `index.html`，无后端、无构建、无依赖。
- 数据全部在 `localStorage`：
  - `junshi_conv_v1` 对话列表　`junshi_act_v1` 当前对话
  - `junshi_cfg_v1` 接口配置　`junshi_persona_v1` 人设　`junshi_ctx_v1` 背景
  - `junshi_msg_v1` 旧版遗留键（保留作备份，不再读写）
  - `junshi_tts_rate_v1` 朗读语速（代码里预留，界面上没暴露）
- 每次请求只带**最近 24 条**消息（省 token），但人设和背景资料**永远完整**带上。
- 温度固定 0.85。
- 朗读用 `speechSynthesis`，先把正文按 `。！？；\n` 切成句子，再把句子合并成 ≤160 字的块
  （长文一次性读在 iOS 上会被截断）。`getVoices()` 是异步的，所以有 `onvoiceschanged` + 800ms 兜底。
- 「点某个字开始读」用 `caretRangeFromPoint` 取字，然后**回退到句首**——不然会出现"点第 20 字、从第 19 字读起"的错位。
- 语音输入用 `webkitSpeechRecognition`（iOS Safari 不提供，所以按钮自动隐藏）。
- 表情是系统 emoji，**不是腾讯的版权图片**；`/名称` 代码在 `mdLite` 里渲染，
  但会先摘出代码块再处理，避免 ``` `/微笑` ``` 和网址被误伤。
- 图片走 OpenAI 多模态格式（`content` 从字符串变成 `[{type:"image_url"},{type:"text"}]`），
  发送前用 canvas 压到最长边 896px / 目标 300KB，PNG 透明底先铺白再转 JPEG。
- 一条消息最多 4 张图，单张原图上限 12MB。
- 接口若返回 `application/json`（不支持流式），会自动退化成一次性返回。
- 接口若报"不支持 image_url"，自动去掉图重发一次（等 `busy` 复位后再发，避免被自己的并发守卫挡住）。
- 详细改动记录见同目录 `更新日志.md`。
