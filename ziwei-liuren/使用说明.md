# 紫微斗数 · 大六壬（iPhone 可用）

一个**纯本地、不联网**的排盘与解读小工具。紫微斗数看命，大六壬断事，两个都能给出**分析、建议和具体解决方法**。

---

## 一、在 iPhone 上怎么用（推荐）

1. **电脑上启动服务**：双击 `启动服务.bat`（会自动打开浏览器，并监听 8848 端口，同时把本机 IP 打印出来）。
2. **手机上打开**：iPhone 的 Safari 输入 `http://电脑的IP:8848`（例如 `http://192.168.1.7:8848`；手机要和电脑连同一个 Wi-Fi）。
3. **加到主屏幕**：Safari 底部「分享」→「添加到主屏幕」。
   → 之后**点图标就能用，且完全离线**（计算全在本机，飞行模式也能排盘）。

> 加桌面图标这一步要在**同一个 Wi-Fi 下访问过一次**才能生效（首次要联网下载页面）。
>
> 若脚本提示「没有可用的 python 或 node」：本机没装这两样也不影响电脑上使用（双击 `启动.bat` 即可）；
> 只是手机访问需要电脑先跑一个本地服务，装个 Python（python.org，安装时勾选 `Add python.exe to PATH`）再跑一次即可。
> 注意 Windows 应用商店那个 `python` 是占位符，不算数，脚本已会自动跳过。

## 二、不想开服务也能用

直接双击 `index.html`（或 `启动.bat`）用电脑浏览器打开，按 F12 → 点手机图标切到手机视图即可。

## 三、紫微斗数怎么填

| 字段 | 说明 |
|---|---|
| 出生日期 | **公历**（阳历）。支持 1900-01-31 ~ 2100-12-31 |
| 出生时间 | 尽量精确到小时；不知道就填大概时段（影响时支，进而影响命宫） |
| 性别 | 决定大限顺逆行（阳男阴女顺行、阴男阳女逆行） |
| 闰月算法 | **十五前本月、十六起下月**（推荐，与主流排盘一致）／闰月按本月／闰月按下月 |
| 定命宫用的月 | **节气月**（以立春、惊蛰等「节」分月，专业排盘主流）／**农历月**（初一换月，部分在线工具做法） |
| 出生地 | 用于真太阳时校正。中国统一用东经 120° 的钟表时间，但新疆、西藏、东北与 120° 差很多 |
| 当前年龄 | 用于定位当前大限；留空按今年自动估算（虚岁） |

**为什么要真太阳时**：乌鲁木齐用北京时间，钟表 01:00 时当地真太阳时才 22:51（前一天），时支会差两个时辰，命盘完全不同。默认开启校正。

## 四、大六壬怎么用

1. 写下**具体要问的事**——越具体越有用。好问题：「这个月这笔合作能不能签下来」；效果差的问题：「我最近运气怎么样」。
2. 点「起课」。起课时刻默认取**此刻**——传统讲「心动即占」，你决定要问的这一刻就是占时。
3. 想复盘旧事，把「起课方式」改成「手动指定」，填当时的时间。

**排盘依据**：《六壬大全》《大六壬指南》
- 月将以**中气**换将（雨水后用亥将，春分后用戌将……）
- 十二天将按「天盘贵人所压地盘宫」判顺逆：落 亥子丑寅卯辰 顺治，落 巳午未申酉戌 逆治
- 采用贵人临辰戌的「移神换将」（临辰用申、临戌用寅）
- 三传按九宗门顺序取：伏吟 → 返吟 → 八专 → 贼克 → 比用 → 涉害 → 遥克 → 昴星／别责

## 五、结果怎么读

### 紫微斗数
- **命盘总述**：一句话点出这张盘的核心特征 + 当前大限落点
- **十二宫图**：传统「巳午未申／辰…酉／卯…戌／寅丑子亥」布局，命宫描金边、身宫紫边，右下角是该宫的大限岁数
- **优势与风险**：都有具体星曜支撑
- **十二宫详解**：每宫给 0-100 的状态分 + 解读 + 一句可执行建议
- **事业/财富/感情/健康**：分方向给结论
- **当前与未来时机**：结合大限、流年
- **行动清单**：分「现在／今年／未来三年」，每条都注明命盘依据

### 大六壬
- **天地盘**：每格上字是天盘神、中字是天将、下字是地盘宫；金框为占时宫，划掉的是旬空
- **四课 / 三传**：标出贼克关系、六亲、空亡
- **总断**：吉凶倾向 + 0-100 评分 + 把握度
- **针对你的问题**：直接回应你问的那件事
- **断课要点 / 判断依据**：每条依据都引用真实课面
- **该做与不该做 / 时机 / 解决方法（分步）**

## 六、准确性说明

已经过的校验：

| 模块 | 校验方式 | 结果 |
|---|---|---|
| 农历、干支、节气 | 与权威历法库 lunar_python 逐项交叉比对 | 全部一致（1900 闰八月、2023 闰二月、2033 闰冬月等边界均正确） |
| 紫微全盘 | 与开源权威实现 iztro 对 **308 张命盘全字段**逐项比对（五行局／农历／宫名／宫干支／十四主星／辅煞星／四化／长生十二神／大限／命主身主） | **308 张全部一致** |
| 六壬四课三传 | 720 种课式（60 甲子 × 12 盘）遍历 | 无异常；井栏射六日、八专五日、伏吟返吟等特殊课体与古籍吻合 |
| 六壬天将 | 对照《六壬大全·卷二》《大六壬指南》原文规则 | 顺逆判据、辰戌移换、十二将序位均按原文实现 |
| 浏览器实测 | 真机页面逐案例点击排盘／起课，检查渲染完整性与控制台报错 | 12 宫盘、天地盘、四课三传齐全，无脚本报错 |

**紫微几个容易踩的口径**（都已在代码里注明并与 iztro 对齐）：

- **宫干用农历年干**（正月初一换年）起五虎遁；**四化、流年诸星用节气年干**（立春换年）。两套口径不能混用，混了就会出现「立春到春节之间出生的人宫干全错」。
- **命主**按命宫地支定、**身主**按农历年支定。
- **火星铃星**按年支三合局起子时：申子辰火寅铃戌、寅午戌火丑铃卯、巳酉丑火卯铃戌、亥卯未火酉铃戌（144 格逐格核对过）。
- **大限**由五行局起、阳男阴女顺行；**长生十二神**起点为水二局申、木三局亥、金四局巳、土五局申、火六局寅，方向同样依生年阴阳与性别。

**重要提醒**：历法与排盘规则是精确的，但**断语本身是经验模型**。这个工具给的是参考视角和行动思路，不是命运判决书——**重大决定请自己拿主意**。

## 七、文件说明

```
紫微六壬/
├── index.html           主程序（手机页面，全部界面与渲染）
├── manifest.json        PWA 清单（加到主屏幕用）
├── sw.js                离线缓存
├── icon-180/192/512.png App 图标
├── 启动.bat             直接打开网页
├── 启动服务.bat         启动本地服务（供手机访问）
├── js/
│   ├── calendar_data.js 历法数据（1900-2100 农历与节气）
│   ├── calendar.js      历法内核（农历/干支/节气/月将/真太阳时）
│   ├── ziwei.js         紫微斗数排盘引擎
│   ├── ziwei_read.js    紫微命盘解读与建议引擎
│   ├── liuren.js        大六壬起课引擎
│   └── liuren_read.js   大六壬断课与建议引擎
├── build/               数据生成与校验脚本、参考实现对照环境（开发者用，可删）
│   └── final-*.png      两张成品截图（紫微命盘 / 六壬课盘）
└── test_*.js            自测脚本（开发者用，可删）
    ├── test_calendar.js        历法与 true solar 校验（对照 lunar_python）
    ├── test_ziwei.js           紫微单盘逐项校验
    ├── test_ziwei_vs_iztro.js  紫微 × iztro 308 盘全字段比对（金标准）
    ├── test_liuren.js          六壬四课三传、720 课式遍历
    └── test_e2e.js             排盘→解读→渲染 端到端
```

跑一遍全部自检（需要 Node）：

```
node test_calendar.js && node test_ziwei.js && node test_ziwei_vs_iztro.js && node test_liuren.js && node test_e2e.js
```

界面上「ⓘ 说明」标签里也内置了这份使用要点。
