## 手机上怎么用

### iPhone（推荐，可离线用）
1. Safari 打开上面的地址（**必须用 Safari**，微信内置浏览器不能加桌面图标）。
2. 底部「分享」按钮 → **添加到主屏幕** → 添加。
3. 之后桌面上会多一个「紫微六壬」图标，**点开就能用，飞行模式也能排盘**（页面和算法全部缓存在手机本地，不联网、不上传任何信息）。

### 安卓
1. Chrome 打开地址。
2. 右上角「⋮」→ **添加到主屏幕 / 安装应用**。

### 电脑
浏览器直接打开上面的地址即可；也可以按 F12 → 点手机图标切到手机视图看排版。

## 功能

| 页面 | 能做什么 |
|---|---|
| **紫微斗数** | 填公历生日 + 时辰 + 性别 → 排十二宫命盘（主星／辅煞／四化／大限／长生），并给出命盘总述、优势与风险、十二宫逐宫解读、事业财富感情健康分项、当前与未来时机、分「现在／今年／未来三年」的行动清单 |
| **大六壬** | 写下具体要问的事 → 起课（或指定时间复盘旧事），输出天地盘、四课、三传、课体、总断评分、断课要点、判断依据、该做与不该做、分步解决方法 |
| **说明** | 口径与准确性说明 |

几个可切换的口径：闰月算法（默认「十五前本月、十六起下月」）、定命宫用的月（**节气月**＝专业主流／农历月）、真太阳时校正（按出生地经度）。

## 准确性

- 历法（农历、干支、节气、真太阳时）：与权威历法库 `lunar_python` 逐项交叉比对，一致。
- 紫微全盘：与开源权威实现 **iztro** 对 **308 张命盘全字段**（五行局／农历／宫名／宫干支／十四主星／辅煞／四化／长生十二神／大限／命主身主）比对 —— **全部一致**。
- 大六壬：720 种课式（60 甲子 × 12 盘）遍历无异常；井栏射六日、八专课、伏吟返吟等特殊课体与古籍吻合；十二天将顺逆、辰戌移换按《六壬大全》《大六壬指南》原文实现。

> 断语本身是经验模型，工具给的是参考视角和行动思路，**重大决定请自己拿主意**。

## 这份文件从哪来 / 怎么更新

- 线上内容就是仓库里 `ziwei-liuren/` 这个目录。
- 源工程在本地 `紫微六壬/`（含引擎、解读引擎、自测脚本）。
- 更新流程：改完本地文件 → 重新上传 `ziwei-liuren/` 下的对应文件 → 等 1 分钟 Pages 重建。
  页面用的是「离线优先 + 后台更新」的缓存策略，所以**你下次联网打开时会自动拿到新版**，不用手动清缓存；万一没更新，把页面下拉刷新一次即可。

### 自测命令（需要 Node）
```
node test_calendar.js        # 历法（对照 lunar_python）
node test_ziwei.js           # 紫微单盘逐项
node test_ziwei_vs_iztro.js  # 紫微 × iztro 308 盘全字段比对
node test_ziwei_read.js      # 命理解读（4 指定盘 + 60 压力盘）
node test_liuren.js          # 六壬四课三传 + 720 课式
node test_liuren_read.js     # 断课引擎（1063 条断言）
node test_e2e.js             # 排盘→解读→渲染 端到端
```
